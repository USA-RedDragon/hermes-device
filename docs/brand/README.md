# Talaria logo

The master files for the Talaria logo: a winged sandal drawn as one outline (variant C).

| File | Use |
|---|---|
| `talaria-outline.svg` | The logo as an outline, colored by `currentColor`. Use it on any background. |
| `talaria-filled.svg` | The logo filled with `currentColor`. |
| `icon.svg` | The app icon: the white outline on an accent-blue (#2f6fde) rounded square. |
| `icon-maskable.svg` | The app icon with the safe zone that maskable icons need. |
| `badge.svg` | The filled logo in white, for notification badges. |

Make PNGs and other sizes from these files. Do not draw the logo again by hand.
