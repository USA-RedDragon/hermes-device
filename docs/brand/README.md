# Talaria logo

The master files for the Talaria logo: a winged sandal drawn as one outline. The previews sit on grey so the black and white files both show.

| Preview | File | Use |
|---|---|---|
| ![Outline logo](talaria-outline.svg) | `talaria-outline.svg` | The logo as an outline, colored by `currentColor` (black when used as an image). Use it on any background. |
| ![Filled logo](talaria-filled.svg) | `talaria-filled.svg` | The logo filled with `currentColor`. |
| ![App icon](icon.svg) | `icon.svg` | The app icon: the white outline on an accent-blue (#2f6fde) rounded square. |
| ![Maskable app icon](icon-maskable.svg) | `icon-maskable.svg` | The app icon with the safe zone that maskable icons need. |
| ![Notification badge](badge.svg) | `badge.svg` | The filled logo in white, for notification badges. |

Make PNGs and other sizes from these files. Do not draw the logo again by hand.
